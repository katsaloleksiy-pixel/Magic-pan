# Магическая кастрюля — бот, который учится вашему стилю монтажа и монтирует по нему

**Учёба:** бот принимает ваши готовые ролики, разбирает их и показывает «паспорт стиля». Паспорт можно поправить обычным сообщением.
**Монтаж:** вы присылаете исходники — бот расшифровывает речь, убирает паузы и дубли, ставит перебивки, вшивает субтитры по паспорту и присылает готовый ролик. Правки — текстом.

## Файлы проекта

| Файл | Зачем |
| --- | --- |
| `Magic pan-server.js` | Сам бот. Внешних библиотек нет |
| `Magic pan-Dockerfile` | Сборка для Railway: бот + свой сервер Telegram Bot API + ffmpeg + шрифты |
| `Magic pan-README.md` | Эта инструкция |

## Что получить перед установкой

1. **Токен бота.** В Telegram напишите @BotFather → `/newbot`. Создайте нового бота: не используйте токен от других проектов.
2. **api_id и api_hash.** Зайдите на https://my.telegram.org под своим номером → «API development tools» → создайте приложение. Они нужны, чтобы бот принимал файлы больше 20 МБ и отправлял готовые ролики больше 50 МБ.
3. **Ключ Gemini.** https://aistudio.google.com/apikey. На бесплатном тарифе Google использует присланные материалы для улучшения своих продуктов, на платном — нет.
4. **Ключ ElevenLabs (необязательно).** Нужен, чтобы бот говорил вашим голосом: https://elevenlabs.io → тариф со «Instant Voice Cloning» (Starter, около $5 в месяц, ≈30 минут озвучки) → Profile → API Keys. Переменная `ELEVENLABS_API_KEY`. Без ключа всё остальное работает как раньше.

## Установка на Railway

1. Загрузите `Magic pan-server.js` и `Magic pan-Dockerfile` в репозиторий на GitHub (в корень).
2. Railway → New Project → Deploy from GitHub repo → выберите репозиторий.
3. В сервисе откройте Variables и добавьте:

| Переменная | Значение |
| --- | --- |
| `RAILWAY_DOCKERFILE_PATH` | `Magic pan-Dockerfile` |
| `BOT_TOKEN` | токен от @BotFather |
| `GEMINI_API_KEY` | ключ Gemini |
| `TELEGRAM_API_ID` | api_id с my.telegram.org |
| `TELEGRAM_API_HASH` | api_hash с my.telegram.org |

4. Добавьте к сервису Volume с путём `/data`. Там хранятся примеры, паспорт стиля и исходники текущего ролика; без него всё пропадёт при обновлении.
5. Публичный домен не нужен.
6. После запуска сразу напишите боту `/start`. Первый, кто это сделает, становится владельцем — остальным бот отвечать не будет.

**Обновление:** замените `Magic pan-server.js` и `Magic pan-Dockerfile` в репозитории — Railway пересоберёт бота сам. Примеры и паспорт сохранятся на Volume.

## Как пользоваться

### Учёба (/learn)
1. Пришлите боту 5–15 своих готовых роликов.
2. Нажмите «Собрать паспорт стиля». Придёт краткая версия (8 строк); полная — по кнопке «📄 Подробно».
3. Если что-то не так — нажмите «Поправить» и напишите правку: «субтитры у меня всегда жёлтые».
4. Нажмите «Всё верно» — бот перейдёт в режим монтажа.

### Меню
Под полем ввода всегда есть кнопки: **🆕 Новый ролик**, **🤖 Ролик из темы**, **🗂 Мои ролики**, **📚 Медиатека**, **🧬 Мой голос**, **ℹ️ Статус**. Команды дублируют их, но запоминать не обязательно.

### Монтаж (/edit или /new) — 3 этапа
Бот ведёт по шагам одной «карточкой», которая обновляется на месте, чтобы чат не засорялся. Прогресс виден по точкам 🔵⚪⚪. Объяснение этапов показывается только в первый раз.

1. **Материалы.** Кнопками выбираете, что сейчас загружаете, и присылаете файлы. Переключаться можно в любом порядке — например, сначала перебивки, а потом записать голос поверх:
   - **🎞 Перебивки** — видео для картинки: продукт, процесс, место. Звук и речь в них не слушаются. ИИ разбирает их одним заходом, когда вы нажмёте «Дальше» — удалённые и заменённые файлы не тратят деньги.
   - **🎤 Видео с речью** — где вы говорите в камеру; речь расшифровывается и идёт в ролик.
   - **🎙 Голос** — голосовое (зажмите микрофон в Telegram) или аудиофайл; под голос бот подберёт картинку.
   Голосовое в любом режиме считается голосом. Текущий режим отмечен ✅, в сообщении этапа видно, что уже загружено.
2. **Пожелания.** Коротко, каким должен быть ролик: «30 секунд, начни с цены». Или «🎨 На выбор ИИ» — по паспорту стиля.
3. **Монтаж.** Сводка: материалы, пожелания, медиатека, прогноз расхода. «▶️ Смонтировать» — ролик придёт в чат. Под готовым роликом — сколько всего потрачено на него; цена каждого варианта видна в «Мои ролики».

Пока файл обрабатывается, у него своё сообщение с таймером; когда готово, оно исчезает, а итог попадает в карточку («Загружено: 🎞 перебивки: 3 · 🎙 голос: 1»). Остаются только ошибки и замены. Подробности по каждому файлу — в «ℹ️ Статус».

Файл попал не в тот режим — `/broll 3` сделает исходник 3 перебивкой, `/talk 3` — видео с речью. `/broll`, `/talk`, `/voice` без номера переключают режим загрузки.

Какие сочетания понимает бот:
   - **видео с речью + перебивки** — ваша речь, поверх — перебивки по смыслу;
   - **перебивки + голос** — закадровый голос, видеоряд подбирается под каждую фразу;
   - **видео с речью + голос + перебивки** (гибрид) — фразы обоих видов чередуются, голоса не накладываются;
   - **только перебивки** — ролик из картинки в вашем темпе.

**Важно: дожидайтесь бота.** Пришлите файлы этапа и подождите сводку «Исходников: …» с кнопкой «Дальше». Если нажать «Дальше», пока файлы ещё обрабатываются, бот попросит подождать и сам пришлёт следующий этап, когда закончит.

### Мой голос (/myvoice) и ролик из текста (/say)
Бот может озвучивать текст вашим голосом — через ElevenLabs (нужен ключ, см. выше).
1. **Образцы.** Все ваши голосовые из роликов уже считаются образцами. Можно добавить отдельно: `/myvoice` → «🎙 Добавить образцы» → наговорите 1–2 минуты спокойно, без музыки и шума, как в ролике → «Готово». Лучше меньше, но чище.
2. **Обучение.** `/myvoice` → «🧬 Обучить голос». Бот склеит лучшие образцы (до 2,5 минут), выровняет громкость, уберёт паузы и обучит клон. Перед этим попросит подтвердить, что голос ваш: клонировать чужой голос без согласия нельзя. После обучения придёт проба. Не похоже — добавьте образцов и «🔁 Обучить заново».
3. **Озвучка в ролике.** В мастере на этапе «Материалы» кнопка «⌨️ Текст → мой голос»: напишите текст, бот озвучит и добавит как голос. Время каждого слова приходит от ElevenLabs, поэтому субтитры по словам у такой озвучки точные.
4. **Ролик из текста одной командой.** `/say Сегодня коптим скумбрию…` — бот озвучит текст, включит медиатеку, подберёт перебивки из ваших прошлых видео и покажет этап «Монтаж». Остаётся нажать «▶️ Смонтировать». Чтобы было из чего выбирать, пополните медиатеку (`/lib`).

Расход ElevenLabs считается символами и списывается с его тарифа (≈1000 символов на минуту речи); сколько озвучено — в `/myvoice` и `/status`. Образцы голоса отправляются на серверы ElevenLabs и хранятся там как ваш голос; удалить — «🗑 Удалить голос».

### Голосом вместо текста
Везде, где бот ждёт текст, можно наговорить голосовое: тема для сценария, правка сценария или паспорта, пожелания к ролику на этапе 2, правка к готовому ролику. Бот расшифрует («🎙 «короче»») и сделает. После готового ролика голосовое вызывает вопрос «Это правка, материал или новый ролик?» — выберите кнопкой.

### Сценарий от ИИ (🤖 Ролик из темы, /script)
Напишите или наговорите задание: «про копчёную скумбрию на ольхе, почему без химии, на 20 секунд, начни с цены». Бот отделит тему от пожеланий (они попадут в ролик) и напишет текст озвучки в вашей манере: учитывает паспорт стиля, типичную длину ваших роликов и расшифровки вашей речи из медиатеки (слова, длину фраз, обращения). Первая фраза — крючок, финал — ваш обычный призыв. Факты, которых нет в теме, он не выдумывает, а помечает «[уточните: …]».

Вместе со сценарием бот проверяет, хватает ли картинки: смотрит описания всех видео в медиатеке и в текущем ролике и пишет «🎞 Картинка: есть — …» и «📹 Доснять: …». Кнопка **📹 Добавить видео по теме** открывает приём перебивок с этим списком; досняли, прислали — «🗣 Озвучить сценарий и собрать». Без досъёмки ролик тоже соберётся, но картинка будет повторяться.
- **✏️ Поправить** — «короче», «начни с цены», «добавь про доставку» (текстом или голосом).
- **🔄 Другой вариант** — другой крючок и ход мысли.
- **🗣 Озвучить и собрать** — если голос обучен: озвучка вашим голосом → перебивки из медиатеки → этап «Монтаж». Без клона голоса кнопка «🎙 Запишу голосом»: бот покажет текст и переведёт в режим голоса — читаете его голосовым.
Сценарий можно вызвать и внутри ролика: «⌨️ Текст → мой голос» → «🤖 Сценарий от ИИ» — озвучка добавится к уже загруженным материалам.

### Медиатека (/library)
**Пополнить без ролика:** `/lib` (или «➕ Пополнить медиатеку» в `/library`). В этом режиме каждое видео сразу разбирается ИИ: бот находит планы, отмечает удачные кадры для перебивок и описывает, что в кадре; голосовые сохраняются как образцы голоса. Кадры не вырезаются в отдельные файлы — хранится разметка (секунды, качество, описание), а режет бот уже при монтаже, так ничего не теряется в качестве. Закончили — «✅ Готово — к монтажу».

Всё, что вы присылаете для роликов, остаётся в профиле вместе с разбором ИИ: описанием планов и расшифровкой речи. Это и есть медиатека.
- На этапе 4 перед монтажом есть переключатель **«📚 Медиатека»**. Включён — ИИ может брать перебивки из ваших прошлых видео. По расшифровке и описанию он понимает, о чём каждое видео, и берёт только подходящее; исходники текущего ролика в приоритете. Выбор запоминается для следующих роликов.
- Если прислать файл, который уже есть в медиатеке (тот же файл из Telegram), бот возьмёт готовый разбор и не потратит деньги на ИИ.
- `/library` — список и занятое место, `/libdel 12` — удалить файл, кнопка «🗑 Очистить медиатеку». Когда место кончается (`LIBRARY_MAX_MB`), самые старые файлы удаляются сами; файлы текущего ролика не трогаются.

### Кнопки под готовым роликом
- **✏️ Правка** — напишите, что поправить; получится новый вариант. Правку можно писать и сразу сообщением.
- **🔄 Другой вариант** — ИИ смонтирует ту же историю иначе: другой крючок, порядок, перебивки, темп. Прошлые варианты он видит и не повторяет.
- **✅ Всё подходит** — вариант отмечается финальным (виден в истории).
- **⋯ Ещё** — остальные действия: копии, замена исходника, прошлый вариант, мои ролики, новый ролик.
- **🧬 Копии для повторной публикации** — 3, 5 или 10 копий с еле заметными отличиями: кадрирование, наклон, скорость, цвет, длина, сжатие, метаданные. Без ИИ — бесплатно. Гарантировать, что Instagram посчитает копии новыми, нельзя: его алгоритмы закрыты, а массовые повторы одного ролика могут нарушать его правила.
- **🔁 Заменить исходник** — выберите любой исходник (речь, голосовое, перебивку) и пришлите новый файл; затем «▶️ Смонтировать» — новый вариант с заменой. Там же можно добавить речь или перебивки.
- **↩️ Прошлый вариант** — вернуть вариант, из которого сделан текущий.
- **🗂 Мои ролики** (кнопка меню или `/history`) — все готовые ролики и их варианты. Откройте ролик, выберите вариант — бот пришлёт его с кнопками правок; новые версии добавятся в историю, старые останутся. Так удачный ролик можно переделать и выложить снова. Хранятся последние 5 роликов вместе с исходниками (`KEEP_PROJECTS`).

На любой этап можно вернуться кнопками «⬅️ Назад». Файл попал не в тот этап — `/broll 3` сделает исходник 3 перебивкой, `/talk 3` — видео с речью.

Какие сочетания понимает бот:
   - **речь в кадре + перебивки** — ваша речь, поверх — перебивки по смыслу;
   - **голосовое + перебивки** — закадровый голос, видеоряд подбирается под каждую фразу;
   - **речь в кадре + голосовое + перебивки** (гибрид) — фразы обоих видов чередуются в сценарии, голоса не накладываются;
   - **только видео без речи** — ролик из картинки в вашем темпе.

Что бот делает при монтаже:
- выбирает лучший дубль каждой мысли и выкидывает оговорки и обрывы;
- вырезает паузы в речи длиннее 0,4 с;
- прячет склейки в речи в кадре: на месте разреза (вырезанная пауза, другой дубль) ставит перебивку примерно на секунду до и после — длительность ИИ выбирает сам (0,5–2 с, 0 — если по вашему стилю нужен заметный jump cut). В подписи к ролику — «склеек спрятано: N». Попросить иначе можно правкой: «не прячь склейки» или «перебивки на склейках короче»;
- ставит перебивки по смыслу сказанного;
- делает наезды на говорящего, если так у вас в паспорте;
- вшивает субтитры по словам — цвет, размер, место и выделение слов берутся из паспорта;
- выравнивает громкость под соцсети;
- если перебивка снята на 60 кадров в секунду и больше, может плавно замедлить её вдвое (120 fps — вчетверо): продлить удачный кадр, закрыть нехватку видео, подчеркнуть деталь. Речь в кадре не замедляется. Снимайте перебивки в 60 fps — это даёт боту ещё один приём;
- кадр — как в ваших примерах (обычно вертикальный 1080×1920);
- частота кадров — как у исходников (24, 25 или 30; 60 → 30). Если снимать в 25 и выдавать 30, каждый пятый кадр дублируется и видео подёргивается — поэтому бот подстраивается, а не наоборот. Лучше снимать все исходники одного ролика с одной частотой.

**Творческая свобода ИИ.** По умолчанию включена: ИИ не только копирует паспорт, но и усиливает ролик ради удержания — крючок в первые 1–2 секунды (без «всем привет»), смена картинки каждые 2–4 секунды, вырезание воды, сильный финал. Стиль автора при этом остаётся узнаваемым, а ваши пожелания важнее всего. В заметках к ролику ИИ пишет, что сделал ради удержания. Выключить (строго по паспорту) — `/creative`, включить — ещё раз `/creative`.

Музыку бот пока не добавляет — её удобнее поставить в Instagram при публикации.

Команды: `/status` — что загружено и сколько потрачено на ИИ, `/style` — паспорт, `/new` — новый ролик, `/edit` и `/learn` — режимы, `/broll` и `/talk` — этап загрузки (с номером — переназначить исходник), `/creative` — творческая свобода ИИ вкл/выкл, `/history` — готовые ролики и варианты, `/library` — медиатека, `/lib` — пополнить её, `/myvoice` — мой голос, `/script тема` — сценарий от ИИ, `/say текст` — ролик из текста, `/del 3` — убрать пример или исходник, `/reset` — удалить всё.

## Необязательные переменные

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `ALLOWED_USERS` | пусто | Номера пользователей Telegram через запятую, кому разрешён доступ. Если задано — правило «первый /start» не действует |
| `GEMINI_MODEL` | `gemini-3.8-flash` | Модель ИИ. Дешевле: `gemini-3.1-flash-lite` |
| `GEMINI_FALLBACK_MODEL` | `gemini-3.1-flash-lite` | Запасная модель, когда основная перегружена. Пустое значение — не переключаться |
| `TOK_PER_SEC` | `70` | Сколько токенов Gemini тратит на секунду видео — для прогноза расхода |
| `PRICE_IN` / `PRICE_OUT` | `0.75` / `3.75` | Цена 1 млн входных / выходных токенов, $. Нужна для подсчёта расхода |
| `KEEP_PROJECTS` | `5` | Сколько прошлых роликов хранить вместе с исходниками для `/history`. Больше — больше места на Volume |
| `ELEVENLABS_API_KEY` | пусто | Ключ ElevenLabs — включает «Мой голос» и `/say` |
| `ELEVENLABS_MODEL` | `eleven_multilingual_v2` | Модель озвучки. Понимает русский и украинский |
| `VOICE_SAMPLE_SEC` | `150` | Сколько секунд образцов отдавать на обучение (ElevenLabs советует 1–2 мин, не больше 3) |
| `TTS_MAX_CHARS` | `2500` | Предельная длина текста для одной озвучки |
| `LIBRARY_MAX_MB` | `2500` | Сколько места на Volume может занять медиатека. Сверх этого удаляются самые старые файлы |
| `CUT_COVER` | `1` | Секунд перебивки до и после склейки в речи, если ИИ не указал сам |
| `AI_PARALLEL` | `3` | Сколько исходников ИИ разбирает одновременно |
| `SCENE_THRESHOLD` | `0.3` | Чувствительность поиска склеек в примерах. Меньше — находит больше |
| `PAUSE_MAX` | `0.4` | Паузы в речи длиннее этого (в секундах) вырезаются |
| `MAX_SOURCE_SEC` | `1800` | Предельная длина одного исходника, секунд |
| `MAX_PROJECT_SEC` | `3600` | Предельная длина всех исходников ролика вместе, секунд |
| `SUB_FONT` | `Montserrat ExtraBold` | Шрифт субтитров. Если его нет — берётся DejaVu Sans |
| `DATA_DIR` | путь Volume | Где хранить данные |

## Что важно знать

- При первом запуске бот переключается с общего сервера Telegram на свой. Вернуться на общий можно не раньше чем через 10 минут.
- Без `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` бот тоже работает, но принимает файлы только до 20 МБ и отправляет ролики до 50 МБ.
- Пока бот работает, в шапке чата видно «печатает…», а в сообщении со статусом идёт таймер. Если серверы Google перегружены, бот сам ждёт, повторяет и при необходимости переключается на запасную модель.
- Если сервер перезапустился посреди работы, бот сам продолжит приём и разбор файлов, а прерванный монтаж предложит запустить заново.
- Ролики и исходники отправляются в Gemini на разбор и сразу после него удаляются с серверов Google.
- Время слов в субтитрах рассчитывается по длине слов внутри фразы: фраза целиком попадает точно, отдельные слова — приблизительно.
- Volume на 5 ГБ. Для истории бот хранит исходники и все варианты последних 5 роликов — если ролики тяжёлые, уменьшите `KEEP_PROJECTS`. Если места мало, бот предупредит.
