# Монтажёр — бот, который учится вашему стилю монтажа

Этап 1: бот принимает ваши готовые ролики, разбирает их и показывает «паспорт стиля». Паспорт можно поправить обычным сообщением. Монтаж новых видео по паспорту — следующий этап.

## Файлы проекта

| Файл | Зачем |
| --- | --- |
| `Magic pan-server.js` | Сам бот. Внешних библиотек нет |
| `Magic pan-Dockerfile` | Сборка для Railway: бот + свой сервер Telegram Bot API + ffmpeg |
| `Magic pan-README.md` | Эта инструкция |

## Что получить перед установкой

1. **Токен бота.** В Telegram напишите @BotFather → `/newbot`. Создайте нового бота: не используйте токен от других проектов.
2. **api_id и api_hash.** Зайдите на https://my.telegram.org под своим номером → «API development tools» → создайте приложение. Они нужны, чтобы бот принимал файлы больше 20 МБ.
3. **Ключ Gemini.** https://aistudio.google.com/apikey. На бесплатном тарифе Google использует присланные материалы для улучшения своих продуктов, на платном — нет.

## Установка на Railway

1. Загрузите `Magic pan-server.js` и `Magic pan-Dockerfile` в репозиторий на GitHub (в корень).
2. Railway → New Project → Deploy from GitHub repo → выберите репозиторий.
3. В сервисе откройте Variables и добавьте:

| Переменная | Значение |
| --- | --- |
| `RAILWAY_DOCKERFILE_PATH` | `Magic pan-Dockerfile` |
| `BOT_TOKEN` | токен от @BotFather |
| `GEMINI_API_KEY` | ключ Gemini |
| `TELEGRAM_API_ID` | api_id с my.telegram.org |
| `TELEGRAM_API_HASH` | api_hash с my.telegram.org |

4. Добавьте к сервису Volume с путём `/data`. Там хранятся ролики-примеры и паспорт стиля; без него всё пропадёт при обновлении.
5. Публичный домен не нужен.
6. После запуска сразу напишите боту `/start`. Первый, кто это сделает, становится владельцем — остальным бот отвечать не будет.

## Как пользоваться

1. Пришлите боту 5–15 своих готовых роликов. Можно сразу несколько.
2. Нажмите «Собрать паспорт стиля».
3. Проверьте паспорт. Если что-то не так — напишите правку обычным сообщением: «субтитры у меня всегда жёлтые».
4. Нажмите «Всё верно».

Команды: `/status` — что загружено и сколько потрачено на ИИ, `/style` — показать паспорт, `/del 3` — убрать пример, `/reset` — начать заново.

## Необязательные переменные

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `ALLOWED_USERS` | пусто | Номера пользователей Telegram через запятую, кому разрешён доступ. Если задано — правило «первый /start» не действует |
| `GEMINI_MODEL` | `gemini-3.8-flash` | Модель ИИ. Дешевле: `gemini-3.1-flash-lite` |
| `SCENE_THRESHOLD` | `0.3` | Чувствительность поиска склеек. Меньше — находит больше |
| `DATA_DIR` | путь Volume | Где хранить данные |

## Что важно знать

- При первом запуске бот переключается с общего сервера Telegram на свой. Вернуться на общий можно не раньше чем через 10 минут.
- Без `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` бот тоже работает, но принимает файлы только до 20 МБ.
- Ролики отправляются в Gemini на разбор и сразу после него удаляются с серверов Google.
- Поиск склеек видит резкую смену картинки. Вырезанные паузы внутри одного плана он может пропускать — их оценивает ИИ.
